# 🧠 脑力训练场 · NeuroArena

一个纯前端、零依赖的大脑训练小游戏合集，覆盖 **推理 · 思维 · 反应 · 维度** 四个认知维度，外加一个 **综合** 模块。
每个模块都支持 **简单 / 普通 / 困难** 三档难度，成绩按难度分别保存。
打开 `index.html` 即可游玩，支持电脑与手机触屏，成绩自动保存在浏览器本地。

## 🎮 五个训练模块

| 技能 | 游戏 | 玩法 | 训练目标 |
|------|------|------|----------|
| 🧩 **推理** | 密码破译（Mastermind） | 根据每次的「●位置对 / ○颜色对」反馈，若干步内演绎出隐藏的颜色密码 | 逻辑演绎、假设检验、排除法 |
| 🧠 **思维** | 数列推理 | 限时内找出数字规律（等差 / 等比 / 斐波那契 / 平方 / 交替 / 双数列 / ×2−1…），选出下一项 | 归纳、抽象、逻辑思维 |
| ⚡ **反应** | 极速反应 | 目标随机出现的瞬间立即点击，统计平均反应毫秒数（抢跑无效） | 反应速度、专注力 |
| 🔷 **维度** | 空间旋转 | 从 4 个图形中选出参考图「旋转后」的样子，避开镜像陷阱 | 空间想象、心理旋转 |
| 🔢 **综合** | 舒尔特方格 | 在乱序方格中按 1→N 顺序依次点击，用时越短越好（点错加时） | 反应、专注、空间注意、视觉搜索 |

### 难度差异一览

| 模块 | 简单 | 普通 | 困难 |
|------|------|------|------|
| 密码破译 | 4 位 / 6 色 / 12 次 | 4 位 / 6 色 / 10 次 | 5 位 / 7 色 / 10 次 |
| 数列推理 | 基础规律 · 70s | 全部规律 · 60s | 追加高级规律 · 52s |
| 极速反应 | 大目标 · 8 次 | 中目标 · 10 次 | 小目标 · 12 次 |
| 空间旋转 | 4 连块 | 5 连块 | 6 连块 |
| 舒尔特方格 | 3×3 | 4×4 | 5×5 |

## 🚀 如何使用（无需构建、无需安装依赖）

**方式一 · 单文件，最省事** —— 下载仓库里的 [`standalone.html`](standalone.html)（已把 HTML/CSS/JS 全部内联成一个文件），双击用浏览器打开即可，手机上用浏览器打开同样能玩，可完全离线。

**方式二 · 克隆后打开**

```bash
git clone <repo-url> && cd ddd
# 直接双击 index.html，或
open index.html          # macOS
python3 -m http.server 8000   # 或起个本地服务器，访问 http://localhost:8000
```

**方式三 · 部署到 GitHub Pages**（得到一个可分享的网址）
仓库 → Settings → Pages → Source 选择该分支与根目录，保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

> `standalone.html` 由 `node scripts/build-standalone.mjs` 从源文件自动生成，改动源码后重新运行即可同步。

## ✨ 特性

- **纯原生**：仅 HTML + CSS + 原生 JavaScript，无任何第三方库或网络请求，可完全离线运行。
- **响应式**：桌面与移动端自适应，支持鼠标点击与触屏。
- **本地存档**：每个游戏的最佳成绩通过 `localStorage` 保存（按难度分别记录），首页实时展示。
- **音效**：使用 Web Audio 即时合成，无需音频素材；右上角可一键开关。
- **深色 / 浅色主题**：右上角一键切换，跟随系统偏好，选择本地记忆；整套配色由 CSS 变量驱动，每个技能有独立主题色。

## 🧪 设计要点

- **难度系统**：每个模块记住上次选择的难度，成绩按 `模块 × 难度` 分别存档（localStorage）。
- **密码破译** 的反馈采用标准 Mastermind 计分（正确处理重复颜色，已通过边界用例测试）。
- **空间旋转** 的图形为随机生成的「手性」多连块（4/5/6 连块）：正确项一定是参考图的**真旋转**（外观必然不同，强制心理旋转），且干扰项中的**镜像**永远不会恰好等于某个旋转，保证答案唯一、无歧义（4/5/6 连块各经上万次随机不变量校验）。
- **数列推理** 的正确答案由生成规则直接计算，必定出现在选项中，干扰项在正确值附近浮动；补齐选项时用独立自增偏移，杜绝碰撞死循环（经 5 万次随机校验）。
- **舒尔特方格** 为经典视觉搜索训练：乱序网格中依次点数，用时+点错罚时作为成绩。
