# 🧠 脑力训练场 · NeuroArena

一个纯前端、零依赖的大脑训练小游戏合集，覆盖 **推理 · 思维 · 反应 · 维度** 四个认知维度。
打开 `index.html` 即可游玩，支持电脑与手机触屏，成绩自动保存在浏览器本地。

## 🎮 四个训练模块

| 技能 | 游戏 | 玩法 | 训练目标 |
|------|------|------|----------|
| 🧩 **推理** | 密码破译（Mastermind） | 根据每次的「●位置对 / ○颜色对」反馈，10 步内演绎出隐藏的四色密码 | 逻辑演绎、假设检验、排除法 |
| 🧠 **思维** | 数列推理 | 60 秒内找出数字规律（等差 / 等比 / 斐波那契 / 平方 / 交替…），选出下一项 | 归纳、抽象、逻辑思维 |
| ⚡ **反应** | 极速反应 | 目标随机出现的瞬间立即点击，统计 10 次的平均反应毫秒数（抢跑无效） | 反应速度、专注力 |
| 🔷 **维度** | 空间旋转 | 从 4 个图形中选出参考图「旋转后」的样子，避开镜像陷阱 | 空间想象、心理旋转 |

## 🚀 运行方式

无需构建、无需安装任何依赖：

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
# 或双击 index.html

# 方式二：起一个本地静态服务器（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

也可直接部署到 GitHub Pages / 任意静态托管。

## ✨ 特性

- **纯原生**：仅 HTML + CSS + 原生 JavaScript，无任何第三方库或网络请求，可完全离线运行。
- **响应式**：桌面与移动端自适应，支持鼠标点击与触屏。
- **本地存档**：每个游戏的最佳成绩通过 `localStorage` 保存，首页实时展示。
- **音效**：使用 Web Audio 即时合成，无需音频素材；右上角可一键开关。
- **深色主题**：现代渐变 UI，每个技能有独立主题色。

## 🧪 设计要点

- **密码破译** 的反馈采用标准 Mastermind 计分（正确处理重复颜色，已通过边界用例测试）。
- **空间旋转** 的图形为随机生成的「手性」五连块：正确项一定是参考图的**真旋转**（外观必然不同，强制心理旋转），且干扰项中的**镜像**永远不会恰好等于某个旋转，保证答案唯一、无歧义（已通过 2 万次随机不变量校验）。
- **数列推理** 的正确答案由生成规则直接计算，必定出现在选项中，干扰项在正确值附近浮动。
