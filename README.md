# 🧠 脑力训练场 · NeuroArena

一个纯前端、零依赖的经典小游戏合集：**2048 · 连线 · 扫雷 · 记忆翻牌**。
每款都支持 **简单 / 普通 / 困难** 三档难度，成绩按难度分别保存。
打开 `index.html` 即可游玩，支持电脑（键盘）与手机（触屏/滑动/长按），成绩自动保存在浏览器本地。

## 🎮 四款游戏

| 游戏 | 玩法 | 计分 |
|------|------|------|
| 🔢 **2048** | 滑动 / 方向键合并相同数字，合成 2048 乃至更高 | 最高分（越高越好） |
| 🔗 **连线**（Flow） | 从圆点按住拖到同色圆点，连线不交叉且铺满整个棋盘 | 最短用时 |

## 🚀 如何使用（无需构建、无需安装依赖）

**方式一 · 单文件，最省事** —— 下载仓库里的 [`standalone.html`](standalone.html)（已把 HTML/CSS/JS 全部内联成一个文件），双击用浏览器打开即可，手机上用浏览器打开同样能玩，可完全离线。

**方式二 · 克隆后打开**

```bash
git clone <repo-url> && cd ddd
# 直接双击 index.html，或
open index.html          # macOS
python3 -m http.server 8000   # 或起个本地服务器，访问 http://localhost:8000
```

**方式三 · 部署到 GitHub Pages**（得到一个可分享的网址）
仓库 → Settings → Pages → Source 选择该分支与根目录，保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

> `standalone.html` 由 `node scripts/build-standalone.mjs` 从源文件自动生成，改动源码后重新运行即可同步。

## ✨ 特性

- **纯原生**：仅 HTML + CSS + 原生 JavaScript，无任何第三方库或网络请求，可完全离线运行。
- **响应式**：桌面与移动端自适应，支持鼠标点击与触屏。
- **本地存档**：每个游戏的最佳成绩通过 `localStorage` 保存（按难度分别记录），首页实时展示。
- **成绩总览**：右上角 📊 汇总各游戏、各难度的最佳成绩明细表。
- **音效**：使用 Web Audio 即时合成，无需音频素材；右上角可一键开关。
- **深色 / 浅色主题**：右上角一键切换，跟随系统偏好，选择本地记忆；整套配色由 CSS 变量驱动，每款游戏有独立主题色。

## 🧪 设计要点

- **难度系统**：每款游戏记住上次选择的难度，成绩按 `游戏 × 难度` 分别存档（localStorage）。
- **连线（Flow）** 的谜题由程序**保证可解**地生成：先用 backbite 算法在网格上生成随机哈密顿路径，再切成若干段，每段两端即一对同色端点——由构造即可铺满整盘。相比随机 DFS 不会指数级回溯、不会卡死；5/6/7 三种尺寸各经 5000 次随机校验（铺满、每段相邻连续且长度≥2、颜色数≤14），并用回溯求解器实测可通关。
- **2048** 支持键盘方向键与触屏滑动；合并、生成、结束判定为标准实现，棋盘越小越难。
- **扫雷** 首次点击必定安全（点开后才布雷，避开首格及其邻居），0 邻雷自动泛洪展开；支持模式切换与长按插旗。
- **记忆翻牌** 记最少步数；成绩总览页汇总各游戏、各难度的最佳成绩。
- **深/浅主题** 由 CSS 变量驱动，跟随系统偏好、可一键切换、本地记忆。
